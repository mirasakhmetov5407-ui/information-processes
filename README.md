# Информационные процессы

Учебный интерактивный веб-проект о действиях, которые выполняют с информацией.

## Что показывает проект
- получение информации;
- обработку информации;
- хранение информации в браузере;
- передачу информации (демонстрация);
- важность защиты информации.

## Как запустить
1. Скачайте или клонируйте репозиторий.
2. Откройте файл `index.html` в браузере.
3. Введите сообщение и нажимайте кнопки, чтобы увидеть разные информационные процессы.

Сервер и установка дополнительных программ не нужны.

## Использованные технологии
- HTML — структура страницы;
- CSS — оформление и адаптация под телефон;
- JavaScript — интерактивные действия;
- localStorage — демонстрация хранения данных в браузере.

## Важно
Кнопка «Передать» только показывает, как выглядит этап передачи. Она не отправляет данные в интернет. Сохранённая информация остаётся в локальном хранилище текущего браузера.
